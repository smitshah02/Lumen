# Archived longitudinal Hugging Face study

This directory preserves the day-one longitudinal data audit, its historical
configuration, and the resulting data dictionary/report. It is a bounded
research study, not an ingestion path or dependency of the production API,
LangGraph, retriever, or final evaluation.

The original relative layout is retained under `scripts/`, `configs/`, and
`reports/` for provenance. These files are not supported operational commands.
